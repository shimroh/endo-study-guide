# PHPT Clinical Workflow

A static, interactive clinical study and workflow page for primary hyperparathyroidism.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, `main`, and `/ (root)`.
5. Save and wait for GitHub to publish the site.

The page runs entirely in the browser and does not transmit entered patient data. Do not enter identifiers or protected health information into a public/shared device.
